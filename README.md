## 💡 What is Solicio?

**Solicio** is a free, open-source, **privacy-first** AI tool that helps content creators instantly find and export the best moments from YouTube videos for TikTok, YouTube Shorts, and Instagram Reels.

Just paste a YouTube link (or upload a video), add your free Gemini API key, and get **smart timestamps** of viral-worthy clips — all processed locally in your browser.

---

## ✨ Key Features

- **🤖 AI Viral Moment Detection** — Powered by Google Gemini AI (auto-detects engaging segments)<img width="1021" height="681" alt="image" src="https://github.com/user-attachments/assets/ce841c4e-b728-48b4-8c01-28d6bbcf0061" />

- **🎥 Smart Timestamps** — Get ready-to-use clip timestamps instantly
- **📱 9:16 Vertical Reframing** — Real-time canvas preview optimized for Shorts/Reels
- **🔒 100% Private** — Everything runs in your browser using FFmpeg.wasm + Canvas (no server uploads)
- **⚡ Fast & Lightweight** — Pure HTML, CSS & JavaScript
- **🆓 Free to Use** — Only needs a free Gemini API key

**Coming soon**: Auto captions, better segment detection, batch export, and more.

## 🚀 Quick Start

### Using the Live App (Recommended)
1. Go to [solicio.samhithnadig.workers.dev](https://solicio.samhithnadig.workers.dev/)
2. Get a **free Gemini API key** → [Google AI Studio](https://aistudio.google.com/apikey)
3. Paste your YouTube link or upload a video file
4. Click **Load Video** → Get AI-generated clip timestamps
5. Preview and export your clips!

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **AI**: Google Gemini API
- **Video Processing**: FFmpeg.wasm + HTML5 Canvas
- **Hosting**: Cloudflare Workers + Vercel

**All heavy lifting happens in the browser** — your videos never leave your device.

---

## 🧩 How It Works

1. You provide a YouTube link or video file
2. Gemini AI analyzes the content/transcript
3. AI returns high-potential clip timestamps
4. You preview and export using local video tools
